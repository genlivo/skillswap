# 愿景（中文版，可扩散）/ Vision — Chinese

> 这是可以转发给任何人的版本。它讲的是"我们要做什么、为什么"，不涉及商业底牌。

---

## 一句话

**让全世界的人，用能教的东西，换想学的东西。**

不是"学语言 App"，是"技能互换市集"。你的母语、你的手艺，就是你的货币。

## 我们为什么做这件事

1. **中国有大量"只会中文、想学外语"的人**，但他们面对的是 HelloTalk 7000 万用户里的几百万分之一，找不到真正对口的人。
2. **中文母语者在海外极度稀缺**——对外国人来说"学中文"是刚需，而我们能供给的不仅是语言，还有左权民歌、小花戏、太行山地域文化这种"别人没见过的内容"。
3. **AI / Agent 技能是一个还没人被占住的品类**。全球想学 Agent 的人指数级增长，而懂这些的人大量在中国。这是我们的护城河。

## 我们怎么做（三个原则）

1. **异步优先，实时其次。** 时差会杀死实时约课，异步 + AI 陪练能覆盖所有时区。语言学习最有效的动作（写→被纠正→理解）异步反而更好。
2. **开放共建，而不是闭门造车。** 平台是网络效应生意，10 个高活跃用户 > 1 万注册僵尸。我们先把愿景公开，让对的人自己走过来。
3. **先成人，后青少年。** 未成年人合规 + 数据出境是这件事最重的部分，先做 18+ 跑通模式，再补青少年版。

## 我们公开什么、保留什么

- **公开**：愿景、路线图、贡献指南、行为准则、基础设施代码、文档工具、翻译
- **保留**：核心匹配算法、变现逻辑、用户隐私数据、AI 模型权重

## 我们要去哪里

一个**全球任何人都能访问**的互教互学乐园：中国孩子能找到外国友人练外语，想学 AI 的人能找到老师，任何人想学任何技能都能找到同伴。
