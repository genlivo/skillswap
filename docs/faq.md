# 常见问题 / FAQ

---

### 这靠谱吗？技术上可行吗？/ Is this feasible?

**技术上 100% 可行**，每一块都有成熟方案，整套能跑在 Cloudflare 上，起步成本 $0。真正的风险在"需求"——所以我们在 Phase 0 先用 3 天、0 代码验证"有没有人愿意交换"。
*Technically 100% feasible, every piece has a mature solution, runs on Cloudflare at $0 start. The real risk is demand — that's why Phase 0 validates it first, in 3 days, zero code.*

### 你们怎么交流？是直播连线吗？/ How do people connect? Livestream?

**不是主打直播。** 跨境实时音视频有物理天花板（约 90% 走中继）。我们优先：**异步文字 + 划词纠错 + 语音留言 + AI 陪练**，实时 1对1 纯音频放到后面。
*Not livestream-first. Cross-border realtime has a physical ceiling (~90% need relay). We prioritize async text + inline correction + voice messages + AI companion; 1:1 audio comes later.*

### 免费吗？/ Is it free?

MVP 阶段完全免费互惠交换。后期才会有付费课程（抽成 10–15%）。平台自身跑在 Cloudflare 免费额度上。
*MVP is free reciprocal exchange. Paid courses (10–15% take) come later. The platform itself runs on Cloudflare's free tier.*

### 我的数据安全吗？涉及未成年人吗？/ Data & minors?

MVP 阶段**先开放 18+**，避开最重的合规包袱。未成年人 + 数据出境（PIPL）是严肃议题，我们会单独准备青少年版与合规流程。
*MVP opens 18+ first to avoid the heaviest compliance load. Minors + cross-border data (PIPL) are serious; we'll prepare a teen version + compliance separately.*

### 为什么用 GitHub 而不是自己偷偷做？/ Why GitHub, not closed?

平台是网络效应生意，冷启动最优解是"把用户变成贡献者"。公开仓库 = 免费的、精准的、全球可发现的流量入口；公开代码 + 真实域名邮箱 = 极稀缺的信任信号。
*A platform is network-effect; the best cold-start is turning users into contributors. A public repo is a free, precise, globally-discoverable entry point; open code + a real domain email is a scarce trust signal.*
