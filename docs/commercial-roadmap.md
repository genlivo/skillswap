# SkillSwap 商业化与分支路线图（草案）

> 围绕"全球技能互换"核心，延伸可独立造血的分支，走向真正商业化。本文为团队启动（2027-01-15）前的战略讨论底稿，非正式承诺。

## 一、核心定位

SkillSwap = 全球点对点互教互学社区（语言 + AI/Agent + 任意技能）。开源、异步、跨时区、真实跨国真人配对 + AI 辅助匹配。

## 二、为什么能商业化

- **供给**：中国大量想提升外语 / AI 能力的年轻人；海外母语者想学中文、了解中国。
- **需求**：家长愿为"地道外语 + AI 素养"付费；出海企业需要跨文化语言培训；自由职业者需要 Agent 接单渠道。
- **差异化**：真实跨国真人配对 + AI 辅助，不是纯录播课。

## 三、候选分支（可并行孵化）

1. **付费训练营**：外语 × AI 双技能训练营（面向中国学生 / 职场人），营期制、客单价清晰。
2. **企业出海培训（B2B）**：为出海企业提供员工外语 + 跨文化 + AI 工具培训，按人头 / 项目收费。
3. **Agent 技能市场**：自由职业者在平台接单（翻译 / 课件 / 自动化），平台抽成。
4. **左权本地赋能**：用 SkillSwap 的 AI / 社区能力反哺本地（文旅内容、农产品电商、社区服务），形成"全球流量 → 本地变现"闭环。
5. **内容 IP**：漫山集式文旅 / 技能短剧，沉淀自有流量。

## 四、变现节奏

免费社区（聚人）→ 付费增值（训练营 / 企业）→ 平台抽成（市场）→ 自有 IP / 本地变现。

## 五、100 天里程碑（自 2027-01-15 起）

- **第 1–33 天（M1）**：团队到位、核心产品打磨、首批内测。
- **第 34–66 天（M2）**：首个付费试点跑通、企业客户破冰。
- **第 67–100 天（M3，约 2027-04-25）**：规模化、上市 / 对外发布。

## 六、风险与合规（内部备忘，不对外）

- "上市 / 原始股东"对外表述需注意：未注册公司的股权安排、公开集资存在合规红线，正式对外前过一遍法律。
