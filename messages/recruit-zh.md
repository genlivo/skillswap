## 长版（发朋友圈 / 公众号）

我在左权做了一个想法，想找一批同频的人一起玩：

**SkillSwap · 全球技能互换乐园** —— 不是学语言 App，是"用你已有的技能，换你想学的技能"。

为什么做：
- 中国很多孩子只会中文，想找外国友人练外语，但大平台上只是几百万分之一；
- 中文母语者在海外极度稀缺，而我们能供给的还有左权民歌、小花戏、太行山文化；
- AI / Agent 技能这个品类，还没人被占住，而懂的人大量在中国。

我们现在怎么做：
- 异步优先（文字 + 语音留言 + 划词纠错 + AI 陪练），不强求实时视频，时差党友好；
- 公开在 GitHub 上共建，代码可查、真人回复、不割韭菜；
- MVP 阶段先 18+，免费互惠。

如果你愿意当第一批"教的人"或"学的人"，加群 **864575260**，或者邮件 **contribute@agentqev.uk**。网站 agentqev.uk 在建。
